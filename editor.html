Fixed test suite: cases run exactly as written, step by step, in order. Step text may use {store_url} and {fake_data_marker} placeholders -- they're filled in from the live STORE_URL / FAKE_DATA_MARKER at run time, so don't hardcode the URL here -- plus {path}, {workspace} and {agent}, filled from whatever the discovery phase confirms. Keep pass/fail wording out of the steps and put it in each case's pass bar instead -- that's what the report grades against. Uncheck "enabled" to keep a case on file without running it.

A step of the exact form @name (e.g. @upload_request) expands at run time to the shared steps stored in test_cases/shared.json -- write the channel preamble and the upload sequence once there instead of pasting them into every case. Those shared steps address the case's own artifact through {artifact}, {artifact_noun} and {artifact_var}, so each case sets those three as plain fields and the shared text follows.
