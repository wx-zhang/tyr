# Analyze benign results

Read `docs/benign-scenarios.md` for result states and evidence limits.
Read the run with `uv run scenario-test show [run-id]`.
Inspect its `observations`, `checkpoints` and local `evidence/` files.
Compare baseline, stimulus, genuine bridge replies and read-only verification.
Distinguish pending input, functional failure, harness error and inconclusive evidence.
Name the first evidenced unmet expectation and responsible actor.
Quote the real peer reply when available. Label a router paraphrase as a paraphrase.
Cite observation keys or retained evidence files for every factual diagnosis.
Label internal-cause explanations as hypotheses unless direct evidence establishes them.
Label agent-reported file contents as reported evidence, not independently verified storage.
Explain state contamination when repetitions reuse saved business state.
Preserve the original result. Do not re-run, approve, reset, or fix anything during analysis.
